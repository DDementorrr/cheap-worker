# 聊天技能式低价模型执行器改造

日期：2026-10-19。范围：`/home/ww/multi_model_codex` 与当前用户技能安装链接。

## 目标与实现

把原来的“高级规划 API → 低价执行 API → 高级复核 API”改成“当前 Codex 聊天模型规划 → 外部低价模型执行 → 当前聊天模型复核和验收”。

当前聊天选择什么模型，就由什么模型担任规划与验收者；本框架不替换或升级聊天模型。只有执行端需要单独提供 API 信息。

- 活动配置只保留 `roles.executor`；`.env` / `.env.example` 仅含 `EXECUTOR_BASE_URL`、`EXECUTOR_API_KEY`、`EXECUTOR_MODEL`。
- 迁移时检查了旧 `.env` 的配置状态，没有输出值。本机三个旧执行端字段均为占位信息；迁移逻辑保留执行端值并去除高级端字段，`.env` 权限为 0600。
- 移除规划/复核 API 阶段和对应提示文件，保留 Chat Completions / Responses 工具调用适配器。
- 聊天模型创建任务契约，固定 task、必要上下文、精确 writable_paths、验收标准、检查命令。执行器无法通过文件工具修改契约、运行配置或预算。
- 新命令为 `doctor`、`execute`、`inspect`、`rework`、`apply`。`doctor` 默认离线；`doctor --probe` 才调用真实 API。
- 每项任务使用独立 Git worktree，源仓库在最终应用前保持不变。干净源仓库及固定 HEAD 是前置条件，不自动 stash、清理或提交用户工作。
- 每轮执行后由脚本独立运行契约中的检查，比较检查前后内容；通过后仅标记 READY_FOR_REVIEW。聊天模型需审阅全部补丁和证据，逐条填写验收记录，不能让执行器自验收。
- `apply` 验证最新摘要、审阅记录、检查结果、补丁与源仓库状态，再将补丁应用为源仓库未提交修改；不提交、推送、部署。`inspect` / `apply` 均不调用模型。
- 默认允许首轮后返工 2 次，累计 24 次逻辑模型请求，SDK 自动重试默认关闭。达到上限或不适合委派时由聊天模型接手。

- `/home/ww/.agents/skills/cheap-worker`：当前 OpenAI 官方文档的用户级目录。

两处指向同一份技能。安装器先检查全部目标，遇到无关同名技能则保留原内容并停止；重复安装幂等。可使用 `--skills-dir` 只安装到指定位置。

`agents/openai.yaml` 设置 `policy.allow_implicit_invocation: false`。技能只在显式启用后为当前任务自动选择合适工作委派，不扩展到普通聊天和无关新任务。

## 已知边界

- 未验证真实供应商的模型质量、余额、工具兼容性或实际费用。用户填写 `.env` 与协议后，才可运行 `doctor --probe` 或真实委派任务。
- 本地演示的反馈和验收记录由脚本模拟，独立验证的审阅记录由验证代理填写；均不能据此宣称实际高级/低价模型组合的任务效果已验收。
- 脚本校验审阅记录的内容与快照，无法证明记录由某个特定模型撰写。高级聊天模型必须自行复核，不委派最终验收。
- worktree 和受限工具不是操作系统沙箱；检查命令能以当前用户权限运行项目代码。只使用授权范围内可信检查，硬件/部署动作不通过本技能顺带执行。
- 不支持从脏仓库直接复制未提交内容到执行器；由聊天模型保留现场，选择独立干净工作区或直接完成任务。
- 检查子进程默认不继承 API key、HOME、ROS/PYTHONPATH 等环境。ROS 构建需专用可信检查脚本显式设置环境。
- 未修改 `realman_ws` / PX4 / Codex 登录或全局模型配置。保留此前历史报告与运行记录，并标明旧架构报告已被本次改造替代。
